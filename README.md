# NP+ Player · versiones

NP+ Player es el reproductor de video de [NeuroPixel+](https://github.com/neuropixelplus) para revisión y producción: timecode, notas, LUTs, ACES, medidores, goniómetro, control de calidad, secuencias de imágenes y conexión con el NP+ Estudio.

Este repositorio solo publica los **instaladores para Windows** (en *Releases*). El programa instalado busca aquí las versiones nuevas y solo instala un archivo si su huella SHA-256 coincide con la publicada.

**Descargar:** [última versión](https://github.com/neuropixelplus/np-player-releases/releases/latest)

> El instalador todavía no está firmado: Windows puede mostrar «Windows protegió su PC». Pulsa *Más información › Ejecutar de todas formas*.
